# Rules for coding agents

- Never work on main. Create a branch named agent/<short-task> before editing.
- The site is a single static file: index.html with inline CSS. No build step, no frameworks.
- Do not add analytics, trackers, external scripts, or third-party fonts without asking.
- Keep changes small and focused on the requested task.
- Commit with a clear message. Do not push; the owner reviews and pushes.
